WFHB Sunday Recorder

Personal Radio Recording and Google Drive Backup Utility

WFHB Sunday Recorder is a personal desktop application used to record scheduled WFHB radio broadcasts and save recordings to the application owner's Google Drive account.

The application uses Google Drive authorization to upload and organize audio recordings, playlists, and associated metadata.

The application is intended for personal use and is not offered as a public recording service.

Google Drive Access

The application requests permission to create and manage files it uploads to Google Drive. It does not require unrestricted access to existing Google Drive files.
